1 Synesis: In-Memory API (synesis.load)

Verified with synesis 0.16.0

1.1 Introduction

The synesis.load API compiles Synesis projects directly in memory, with no files on disk. It suits:

  • Jupyter Notebooks: interactive analysis of qualitative data
  • Python scripts: automating research pipelines
  • Pandas integration: direct export to DataFrames
  • Testing and prototyping: quick validation of annotations

1.1.1 CLI versus API

Aspect CLI (synesis compile) API (synesis.load)
Input Files on disk Strings in memory
Output Files Dicts, tables, DataFrames
Use Terminal, CI/CD Notebooks, scripts
I/O Reads and writes disk None

To compile a project that is on disk, use synesis.SynesisCompiler("project.synp").compile().

1.2 Installation

pip install synesis
pip install pandas        # optional, for the DataFrame methods
import synesis
print(synesis.__version__)  # e.g. 0.16.0

1.3 Quick Start

Strings start at column 0

Indentation is significant in Synesis. A string whose whole content is indented (common in Python code) is a syntax error: write the text at column 0 or use textwrap.dedent.

import synesis

template = """
TEMPLATE Minimal

SOURCE FIELDS
    OPTIONAL date
END SOURCE FIELDS

ITEM FIELDS
    REQUIRED quote
END ITEM FIELDS

FIELD date TYPE DATE
    SCOPE SOURCE
END FIELD

FIELD quote TYPE QUOTATION
    SCOPE ITEM
END FIELD
"""

project = """
PROJECT Demo
    TEMPLATE "template.synt"
END PROJECT
"""

annotations = {
    "sample.syn": """
SOURCE @ref2024
    date: 2024-06-15
END SOURCE

ITEM @ref2024
    quote: The technology shows promising results.
END ITEM
"""
}

bibliography = """
@article{ref2024,
    author = {Silva, Maria},
    title = {A Study on Technology},
    year = {2024}
}
"""

result = synesis.load(
    project_content=project,
    template_content=template,
    annotation_contents=annotations,
    bibliography_content=bibliography,
)

if result.success:
    print(f"Compiled: {result.stats.item_count} item(s)")
    print(result.to_dataframe("items"))
else:
    print(result.get_diagnostics())

1.4 The synesis.load() Function

1.4.1 Signature

def load(
    project_content: str,
    template_content: str,
    annotation_contents: Optional[Dict[str, str]] = None,
    ontology_contents: Optional[Dict[str, str]] = None,
    bibliography_content: Optional[str] = None,
    dataset_index: Optional[Dict[str, Any]] = None,
    project_filename: str = "<project>",
    template_filename: str = "<template>",
    bibliography_contents: Optional[Dict[str, str]] = None,
    check_codes: bool = False,
) -> MemoryCompilationResult

1.4.2 Parameters

Parameter Type Required Description
project_content str Yes Content of the .synp
template_content str Yes Content of the .synt
annotation_contents Dict[str, str] No {name: content} of the .syn files
ontology_contents Dict[str, str] No {name: content} of the .syno files
bibliography_content str No Content of one .bib
bibliography_contents Dict[str, str] No Several .bib files, merged in dictionary order (do not combine with the previous one)
dataset_index Dict No Pre-loaded TOML records, for ON DATASET fields
check_codes bool No True: one warning per occurrence of a code without a concept (E004); False: one summary (E090)
project_filename str No Virtual name used in error messages
template_filename str No Virtual name used in error messages

The function does not read the disk: the INCLUDE lines of the project are not followed; only what you pass goes in.

1.4.3 Complete Example

import synesis

project = """
PROJECT QualitativeResearch
    TEMPLATE "analysis.synt"
    INCLUDE BIBLIOGRAPHY "refs.bib"
    INCLUDE ANNOTATIONS "interviews.syn"
    INCLUDE ONTOLOGY "concepts.syno"
END PROJECT
"""

template = """
TEMPLATE QualitativeAnalysis

SOURCE FIELDS
    REQUIRED date
    OPTIONAL country
END SOURCE FIELDS

ITEM FIELDS
    REQUIRED quote
    REQUIRED BUNDLE note, chain
    OPTIONAL code
END ITEM FIELDS

ONTOLOGY FIELDS
    REQUIRED description
    OPTIONAL topic
END ONTOLOGY FIELDS

FIELD date TYPE DATE
    SCOPE SOURCE
END FIELD

FIELD country TYPE TEXT
    SCOPE SOURCE
END FIELD

FIELD quote TYPE QUOTATION
    SCOPE ITEM
END FIELD

FIELD note TYPE MEMO
    SCOPE ITEM
END FIELD

FIELD code TYPE CODE
    SCOPE ITEM
END FIELD

FIELD chain TYPE CHAIN
    SCOPE ITEM
    ARITY >= 2
    RELATIONS
        INFLUENCES: Relation of influence
        ENABLES: Enabling relation
    END RELATIONS
END FIELD

FIELD description TYPE TEXT
    SCOPE ONTOLOGY
END FIELD

FIELD topic TYPE TOPIC
    SCOPE ONTOLOGY
END FIELD
"""

annotations = """
SOURCE @silva2024
    date: 2024-03-15
    country: Brazil
END SOURCE

ITEM @silva2024
    quote: Cost is a significant barrier.
    note: The interviewee identifies an economic factor
    chain: Cost -> INFLUENCES -> Adoption
END ITEM

ITEM @silva2024
    quote: Public acceptance eases implementation.
    note: Relation between social and technical factors
    chain: Public_Acceptance -> ENABLES -> Implementation
END ITEM
"""

concepts = """
ONTOLOGY Cost
    description: Economic cost factor
    topic: Economics
END ONTOLOGY

ONTOLOGY Public_Acceptance
    description: Community acceptance
    topic: Social_Factors
END ONTOLOGY

ONTOLOGY Adoption
    description: Technology adoption
    topic: Technology
END ONTOLOGY

ONTOLOGY Implementation
    description: Technical implementation
    topic: Technology
END ONTOLOGY
"""

bibliography = """
@article{silva2024,
    author = {Silva, João and Santos, Maria},
    title = {Factors of Technology Adoption},
    journal = {Brazilian Research Journal},
    year = {2024}
}
"""

result = synesis.load(
    project_content=project,
    template_content=template,
    annotation_contents={"interviews.syn": annotations},
    ontology_contents={"concepts.syno": concepts},
    bibliography_content=bibliography,
)

if result.success:
    print(f"Sources: {result.stats.source_count}")
    print(f"Items: {result.stats.item_count}")
    print(f"Ontologies: {result.stats.ontology_count}")
    print(f"Chains: {result.stats.chain_count}")

Output:

Sources: 1
Items: 2
Ontologies: 4
Chains: 2

1.5 The MemoryCompilationResult Class

1.5.1 Attributes

Attribute Type Description

1.7 Available Tables

Columns derive from the template: each field of the scope becomes a column. A table exists only if there are fields (or data) for it.

Table Columns
sources bibref, the SOURCE fields, source_file, source_line, source_column
items bibref, the ITEM fields, source_file, source_line, source_column
ontologies one column per ITEM CODE/CHAIN field (holding the concept name), the ONTOLOGY fields and the location
chains bibref, from_code, relation, to_code, source_file, source_line, source_column

With the template of the example above:

sources     bibref, date, country, source_file, source_line, source_column
items       bibref, quote, note, code, chain, source_file, source_line, source_column
ontologies  code, chain, description, topic, source_file, source_line, source_column
chains      bibref, from_code, relation, to_code, source_file, source_line, source_column

Simple chains (without RELATIONS) have no named relation.

1.9.2 Cell 2: Read the Project Files

from pathlib import Path

base = Path("my_project")
read = lambda p: p.read_text(encoding="utf-8")

result = synesis.load(
    project_content=read(base / "project.synp"),
    template_content=read(base / "template.synt"),
    annotation_contents={p.name: read(p) for p in base.glob("*.syn")},
    ontology_contents={p.name: read(p) for p in base.glob("*.syno")},
    bibliography_content=read(base / "references.bib"),
)

print(f"Success: {result.success}")

1.10 The compile_string() Function

Parses an isolated fragment, without semantic validation.

def compile_string(content: str, filename: str = "<string>") -> List[Any]
nodes = synesis.compile_string("""
SOURCE @ref2024
    date: 2024-05-20
END SOURCE

ITEM @ref2024
    quote: Sample text.
END ITEM
""")

source, item = nodes
print(source.bibref)   # @ref2024
print(item.quote)      # Sample text.
Node type Block
SourceNode SOURCE
ItemNode ITEM
OntologyNode ONTOLOGY
ProjectNode PROJECT

The quote attribute of ItemNode is only filled by a field named quote; for free names, use item.entries, the list of written occurrences, or synesis.semantic.occurrences.

1.11 Error Handling

1.11.1 Syntax Errors

They raise SynesisSyntaxError:

try:
    result = synesis.load(
        project_content="PROJECT Broken",   # END PROJECT missing
        template_content=template,
    )
except Exception as e:
    print(f"Syntax error: {e}")

1.11.2 Validation Errors

They stay in the result:

result = synesis.load(
    project_content=project,
    template_content=template,
    annotation_contents={"bad.syn": """
ITEM @missing
    quote: No matching SOURCE
    note: x
    chain: Cost -> INFLUENCES -> Adoption
END ITEM
"""},
)

if not result.success:
    print(result.get_diagnostics(verbose=False))
=== ERRORS ===
[!] ITEM `@missing` has no matching SOURCE in this file
