How to Export to Neo4j

A practical guide to building knowledge graphs from Synesis annotations

1 How to Export to Neo4j

This guide shows how to turn your Synesis annotations into a knowledge graph in Neo4j, for network analysis, visualization and querying with AI assistants.

Use this guide if you:

  • Need to explore complex relations between concepts
  • Want to compute centrality, communities or PageRank
  • Want to query the corpus with an assistant over MCP
No database server?

synesis-graph can also write a local ArcadeDB database, with no server or Java to install:

pip install synesis-graph
synesis-graph arcadedb-embedded --project my_project.synp
synesis-graph serve

It also renders an HTML graph that opens in the browser. See the reference.

1.1 Prerequisites

  • Python 3.10+
  • A Synesis project that compiles without errors
  • Neo4j Desktop, Neo4j Server or Neo4j Aura

1.2 Step 1: Install Neo4j

1.2.1 Option A: Neo4j Desktop (local development)

  1. Download from https://neo4j.com/download/
  2. Create a database (DBMS) and choose a strong password
  3. Start it (Start)
Checkpoint ✓

In Neo4j Browser, run:

RETURN "Hello, Neo4j!" AS message

1.2.2 Option B: Neo4j Aura (cloud)

  1. Go to https://neo4j.com/cloud/aura/ and create an instance
  2. Download the credentials file (URI, user, password) and keep it safe
Sensitive data

A cloud database receives the passages of your corpus. Check what your research ethics approval and data protection law allow.

1.3 Step 2: Install synesis-graph

pip install "synesis-graph[neo4j]"
synesis-graph --version
# synesis-graph, version 0.13.1
Former name

The tool used to be called synesis2graph (and before that synesis2neo4j). If you have the old version, remove it with pip uninstall synesis2graph.

1.4 Step 3: Configure the Connection

Create config.toml in the folder you run the command from:

[neo4j]
uri = "bolt://127.0.0.1:7687"      # Aura: neo4j+s://xxxxx.databases.neo4j.io
user = "neo4j"
password = "YourPassword"
# database = "my_corpus"            # optional; default: PROJECT name
# fulltext_analyzer = "english"     # language-aware text search
Security

Never commit config.toml:

echo "config.toml" >> .gitignore

1.5 Step 4: Export

synesis-graph neo4j --project my_project.synp --config config.toml

config.toml is the default, so --config may be omitted. The pipeline compiles the project in memory (an error stops everything before the database is touched), connects, writes the graph, computes the metrics and writes the project context into the ProjectContext vertex.

Checkpoint ✓ 
MATCH (n) RETURN count(n) AS total_nodes

1.6 Step 5: Explore in Neo4j Browser

MATCH (n) RETURN n LIMIT 100
Labels come from your template

A concept node takes the label of the field name: a field category produces :Category; a field criterion, :Criterion. The queries below omit the label so they work on any project. To get to know the graph: MATCH (p:ProjectContext) RETURN p.template_doc.

// a concept and its relations
MATCH path = (c {name: "Cost"})-[r]->(target)
RETURN path
// annotations of a concept, with their location
MATCH (s:Source)<-[:FROM_SOURCE]-(i:Item)-[:MENTIONS]->(c {name: "Cost"})
RETURN s.bibtex, i.citation, i.source_file, i.source_line

1.7 Step 6: Analytical Queries

1.7.1 Most Frequent Concepts

MATCH (c)
WHERE c.mention_count IS NOT NULL
RETURN c.name AS concept, c.mention_count AS frequency, c.source_count AS sources
ORDER BY frequency DESC
LIMIT 10

1.7.2 Co-occurrences

MATCH (i:Item)-[:MENTIONS]->(c1), (i)-[:MENTIONS]->(c2)
WHERE c1.name < c2.name
RETURN c1.name, c2.name, count(DISTINCT i) AS co_occurrence
ORDER BY co_occurrence DESC
LIMIT 20

1.7.3 Most Recurrent Relations

MATCH (c1)-[r:RELATES_TO]->(c2)
RETURN c1.name AS source, r.type AS relation, c2.name AS target, count(r) AS occurrences
ORDER BY occurrences DESC

1.7.4 Bridge Nodes

MATCH (c)
WHERE c.betweenness IS NOT NULL
RETURN c.name AS concept, c.betweenness AS centrality
ORDER BY centrality DESC
LIMIT 10
betweenness requires the GDS plugin

Without GDS use degree, always available.

1.8 Step 7: Update the Graph

Run the same command after new annotations:

synesis-graph neo4j --project my_project.synp
--mode What it does When to use
rebuild (default) wipes and rewrites the graph always correct: mirrors the corpus exactly
update writes only what changed large corpus; does not remove what was deleted from the project

The graph is a derived artifact: the source of truth is the project files. After renaming or deleting material, use rebuild.

1.9 Step 8: Advanced Metrics (Graph Data Science)

Install the Graph Data Science Library plugin on your database (Neo4j Desktop: Plugins) and restart. The pipeline detects it: with it, pagerank, betweenness and community are computed; without it, it warns and continues with the native metrics.

MATCH (c)
WHERE c.pagerank IS NOT NULL
RETURN c.name, c.degree, c.pagerank, c.betweenness, c.community
ORDER BY c.pagerank DESC
LIMIT 20
  • High PageRank: a concept pointed to by other relevant concepts
  • High betweenness: a concept linking clusters
  • Community (Louvain): same number, same cluster; read it according to the projection used (see the reference)

1.10 Querying with an AI Assistant (MCP)

With the graph in Neo4j, the mcp-neo4j-cypher MCP server lets you query it in natural language from Claude Desktop. In claude_desktop_config.json:

{
  "mcpServers": {
    "synesis-neo4j": {
      "command": "uvx",
      "args": ["mcp-neo4j-cypher@0.5.2", "--read-only"],
      "env": {
        "NEO4J_URI": "bolt://localhost:7687",
        "NEO4J_USERNAME": "neo4j",
        "NEO4J_PASSWORD": "your_password",
        "NEO4J_DATABASE": "database_name"
      }
    }
  }
}

The file is in %APPDATA%\Claude\ (Windows) or ~/Library/Application Support/Claude/ (macOS). Keep --read-only. The repository ships a full guide in the mcp/ folder.

1.11 Troubleshooting

1.11.1 Connection refused (bolt://localhost:7687)

Neo4j is not running: click Start or run neo4j start.

1.11.2 Authentication failed

Check the password in config.toml.

1.11.3 Database not found

List the names with SHOW DATABASES and adjust database.

1.11.4 The command stops with compilation errors

synesis compile my_project.synp

Fix what the compiler reports and export again.

1.11.5 Large Loads Are Slow

  • Use --mode update when you only added material
  • An interrupted load leaves the graph marked as incomplete: run a rebuild
