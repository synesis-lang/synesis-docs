Como Exportar para Neo4j

Guia prático para criar knowledge graphs a partir de anotações Synesis

1 Como Exportar para Neo4j

Este guia mostra como transformar suas anotações Synesis em um grafo de conhecimento no Neo4j, para análises de rede, visualização e consulta por assistentes de IA.

Você deve usar este guia se:

  • Precisa explorar relações complexas entre conceitos
  • Quer calcular centralidade, comunidades ou PageRank
  • Quer consultar o corpus com um assistente via MCP
Sem servidor de banco?

O synesis-graph também grava um banco ArcadeDB local, sem instalar servidor nem Java:

pip install synesis-graph
synesis-graph arcadedb-embedded --project meu_projeto.synp
synesis-graph serve

E gera um grafo HTML que abre no navegador. Veja a referência.

1.1 Pré-requisitos

  • Python 3.10+
  • Um projeto Synesis que compila sem erros
  • Neo4j Desktop, Neo4j Server ou Neo4j Aura

1.2 Passo 1: Instalar o Neo4j

1.2.1 Opção A: Neo4j Desktop (desenvolvimento local)

  1. Baixe em https://neo4j.com/download/
  2. Crie um banco (DBMS) e escolha uma senha forte
  3. Inicie o banco (Start)
Checkpoint ✓

No Neo4j Browser, execute:

RETURN "Hello, Neo4j!" AS message

1.2.2 Opção B: Neo4j Aura (nuvem)

  1. Acesse https://neo4j.com/cloud/aura/ e crie uma instância
  2. Baixe o arquivo de credenciais (URI, usuário, senha) e guarde-o em local seguro
Dados sensíveis

Um banco na nuvem recebe os trechos do seu corpus. Confira o que a ética da pesquisa e a lei de proteção de dados permitem.

1.3 Passo 2: Instalar o synesis-graph

pip install "synesis-graph[neo4j]"
synesis-graph --version
# synesis-graph, version 0.13.1
Nome anterior

A ferramenta chamava-se synesis2graph (e antes synesis2neo4j). Se você tem a versão antiga, remova-a com pip uninstall synesis2graph.

1.4 Passo 3: Configurar a Conexão

Crie config.toml na pasta de onde vai executar o comando:

[neo4j]
uri = "bolt://127.0.0.1:7687"      # Aura: neo4j+s://xxxxx.databases.neo4j.io
user = "neo4j"
password = "SuaSenhaAqui"
# database = "meu_corpus"           # opcional; padrão: nome do PROJECT
# fulltext_analyzer = "brazilian"   # busca textual em português
Segurança

Nunca envie config.toml ao Git:

echo "config.toml" >> .gitignore

1.5 Passo 4: Exportar

synesis-graph neo4j --project meu_projeto.synp --config config.toml

config.toml é o padrão, então --config pode ser omitido. O pipeline compila o projeto em memória (um erro interrompe tudo antes de tocar no banco), conecta, grava o grafo, calcula as métricas e grava o contexto do projeto no vértice ProjectContext.

Checkpoint ✓ 
MATCH (n) RETURN count(n) AS total_de_nos

1.6 Passo 5: Explorar no Neo4j Browser

MATCH (n) RETURN n LIMIT 100
Os rótulos vêm do seu template

O nó de conceito recebe o rótulo do nome do campo: um campo category gera :Category; um campo criterio, :Criterio. As consultas abaixo omitem o rótulo para servir a qualquer projeto. Para conhecer o grafo: MATCH (p:ProjectContext) RETURN p.template_doc.

// um conceito e suas relações
MATCH path = (c {name: "Custo"})-[r]->(alvo)
RETURN path
// anotações de um conceito, com a localização
MATCH (s:Source)<-[:FROM_SOURCE]-(i:Item)-[:MENTIONS]->(c {name: "Custo"})
RETURN s.bibtex, i.citation, i.source_file, i.source_line

1.7 Passo 6: Consultas Analíticas

1.7.1 Conceitos mais frequentes

MATCH (c)
WHERE c.mention_count IS NOT NULL
RETURN c.name AS conceito, c.mention_count AS frequencia, c.source_count AS fontes
ORDER BY frequencia DESC
LIMIT 10

1.7.2 Coocorrências

MATCH (i:Item)-[:MENTIONS]->(c1), (i)-[:MENTIONS]->(c2)
WHERE c1.name < c2.name
RETURN c1.name, c2.name, count(DISTINCT i) AS coocorrencia
ORDER BY coocorrencia DESC
LIMIT 20

1.7.3 Relações mais recorrentes

MATCH (c1)-[r:RELATES_TO]->(c2)
RETURN c1.name AS origem, r.type AS relacao, c2.name AS destino, count(r) AS ocorrencias
ORDER BY ocorrencias DESC

1.7.4 Nós de ponte

MATCH (c)
WHERE c.betweenness IS NOT NULL
RETURN c.name AS conceito, c.betweenness AS centralidade
ORDER BY centralidade DESC
LIMIT 10
betweenness exige o plugin GDS

Sem o GDS, use degree, sempre disponível.

1.8 Passo 7: Atualizar o Grafo

Execute o mesmo comando depois de novas anotações:

synesis-graph neo4j --project meu_projeto.synp
--mode O que faz Quando usar
rebuild (padrão) apaga e regrava o grafo sempre correto: reflete exatamente o corpus
update grava só o que mudou corpus grande; não remove o que foi apagado do projeto

O grafo é um artefato derivado: a fonte de verdade são os arquivos do projeto. Depois de renomear ou apagar material, use rebuild.

1.9 Passo 8: Métricas Avançadas (Graph Data Science)

Instale o plugin Graph Data Science Library no seu banco (Neo4j Desktop: Plugins) e reinicie. O pipeline o detecta: com ele, calcula pagerank, betweenness e community; sem ele, avisa e segue com as métricas nativas.

MATCH (c)
WHERE c.pagerank IS NOT NULL
RETURN c.name, c.degree, c.pagerank, c.betweenness, c.community
ORDER BY c.pagerank DESC
LIMIT 20
  • PageRank alto: conceito apontado por outros conceitos relevantes
  • Betweenness alto: conceito que liga agrupamentos
  • Community (Louvain): mesmo número, mesmo agrupamento; interprete segundo a projeção usada (veja a referência)

1.10 Consultar com um Assistente de IA (MCP)

Com o grafo no Neo4j, o servidor MCP mcp-neo4j-cypher permite consultá-lo em linguagem natural no Claude Desktop. Em claude_desktop_config.json:

{
  "mcpServers": {
    "synesis-neo4j": {
      "command": "uvx",
      "args": ["mcp-neo4j-cypher@0.5.2", "--read-only"],
      "env": {
        "NEO4J_URI": "bolt://localhost:7687",
        "NEO4J_USERNAME": "neo4j",
        "NEO4J_PASSWORD": "sua_senha",
        "NEO4J_DATABASE": "nome_do_banco"
      }
    }
  }
}

O arquivo fica em %APPDATA%\Claude\ (Windows) ou ~/Library/Application Support/Claude/ (macOS). Mantenha --read-only. O repositório traz um guia completo na pasta mcp/.

1.11 Solução de Problemas

1.11.1 Connection refused (bolt://localhost:7687)

O Neo4j não está rodando: clique em Start ou execute neo4j start.

1.11.2 Authentication failed

Confira a senha no config.toml.

1.11.3 Database not found

Veja os nomes com SHOW DATABASES e ajuste database.

1.11.4 O comando para com erros de compilação

synesis compile meu_projeto.synp

Corrija o que o compilador apontar e exporte de novo.

1.11.5 Cargas grandes demoram

  • Use --mode update quando só houve acréscimos
  • Uma carga interrompida deixa o grafo marcado como incompleto: rode um rebuild
