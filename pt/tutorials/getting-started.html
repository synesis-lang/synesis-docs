Getting Started with Synesis

Seu primeiro projeto em 30 minutos

1 Bem-vindo ao Tutorial Getting Started

Neste tutorial, nós vamos construir juntos seu primeiro projeto Synesis completo. Ao final, você terá criado um sistema de anotações estruturadas, validado sua consistência e exportado os resultados para análise.

O que você vai construir:

  • Um projeto de análise de entrevistas sobre adoção de tecnologia
  • Um template personalizado definindo campos e regras
  • Anotações interpretativas estruturadas
  • Uma ontologia com códigos conceituais
  • Exportações em JSON, CSV e Excel

Pré-requisitos:

  • Python 3.10 ou superior instalado
  • VS Code (recomendado, mas opcional)
  • 30 minutos de tempo dedicado
Prefere começar conversando?

A Skill do Synesis para o Claude Desktop instala as ferramentas e monta o projeto com você. Este tutorial faz o mesmo caminho à mão, para você entender cada peça.

1.1 Passo 1: Instalar o compilador

Abra o terminal e execute:

pip install synesis

Verifique:

synesis --version

A saída começa assim:

synesis 0.16.0
Checkpoint ✓

Se você vê o número da versão, o compilador está instalado. Se não, veja Troubleshooting.

Para ter validação em tempo real no editor, instale também o servidor de linguagem, o VS Code e a extensão Synesis:

pip install synesis-lsp

As instruções estão no Tutorial Synesis Explorer.

1.2 Passo 2: Criar a estrutura do projeto

Crie uma pasta e inicialize o projeto:

mkdir meu-primeiro-projeto
cd meu-primeiro-projeto
synesis init

O que aconteceu? O Synesis criou cinco arquivos:

meu-primeiro-projeto/
├── project.synp       # arquivo de projeto (orquestrador)
├── template.synt      # template (define os campos)
├── references.bib     # bibliografia
├── annotations.syn    # anotações
└── ontology.syno      # ontologia

O projeto criado é um exemplo pequeno, em inglês, que já compila:

synesis compile project.synp

Nos próximos passos, vamos substituir o conteúdo desses arquivos pelo nosso estudo.

1.3 Passo 3: Definir o template

O template é o contrato entre você e o compilador. Abra template.synt no editor (code template.synt, ou o bloco de notas) e substitua todo o conteúdo por:

TEMPLATE analise version: "1.0"

ITEM FIELDS
    REQUIRED quote, memo, code
    OPTIONAL chain
END ITEM FIELDS

FIELD quote TYPE QUOTATION
    SCOPE ITEM
    DESCRIPTION Citação literal extraída da fonte
    GUIDELINES
        Copie de uma a três frases, exatamente como aparecem na fonte.
        Não corrija nem resuma.
    END GUIDELINES
END FIELD

FIELD memo TYPE MEMO
    SCOPE ITEM
    DESCRIPTION Sua interpretação do trecho
    GUIDELINES
        Explique em uma ou duas frases o que o trecho revela.
        Não repita a citação.
    END GUIDELINES
END FIELD

FIELD code TYPE CODE
    SCOPE ITEM
    DESCRIPTION Conceitos da ontologia de que o trecho é evidência
    GUIDELINES
        Use apenas conceitos definidos na ontologia.
    END GUIDELINES
END FIELD

FIELD chain TYPE CHAIN
    SCOPE ITEM
    ARITY >= 2
    DESCRIPTION Relação causal entre conceitos, quando o trecho a afirma
    RELATIONS
        INIBE: um fator reduz ou impede outro
        FAVORECE: um fator promove ou facilita outro
    END RELATIONS
    GUIDELINES
        Registre a relação somente quando a fonte a afirma.
    END GUIDELINES
END FIELD

ONTOLOGY FIELDS
    REQUIRED descricao, grupo
END ONTOLOGY FIELDS

FIELD descricao TYPE TEXT
    SCOPE ONTOLOGY
    DESCRIPTION Definição do conceito e quando aplicá-lo
    GUIDELINES
        Defina em uma ou duas frases, com o critério de aplicação.
    END GUIDELINES
END FIELD

FIELD grupo TYPE TOPIC
    SCOPE ONTOLOGY
    DESCRIPTION Tema que agrupa o conceito
    GUIDELINES
        Use um único termo, sem espaços.
    END GUIDELINES
END FIELD

O que isso significa?

  • ITEM FIELDS e ONTOLOGY FIELDS dizem quais campos cada bloco aceita e quais são obrigatórios
  • Cada FIELD declara o tipo e o escopo de um campo
  • ARITY >= 2 exige que uma cadeia ligue ao menos dois conceitos
  • RELATIONS fixa as relações permitidas
  • GUIDELINES registra como preencher o campo: é o seu protocolo de codificação, para pessoas e para a IA
Regra de Ouro

O template é a única fonte da verdade. O que você declarar aqui, o compilador valida. O que você usar sem declarar, ele recusa. Os nomes dos campos são seus.

Confira o template:

synesis validate-template template.synt

1.4 Passo 4: Definir a ontologia

Substitua o conteúdo de ontology.syno por:

ONTOLOGY custo
    descricao: Fatores econômicos ligados ao preço e ao investimento necessário
    grupo: fatores_de_adocao
END ONTOLOGY

ONTOLOGY facilidade_de_uso
    descricao: Percepção de simplicidade ou complexidade da tecnologia
    grupo: fatores_de_adocao
END ONTOLOGY

ONTOLOGY utilidade_percebida
    descricao: Crença de que a tecnologia trará benefícios práticos
    grupo: fatores_de_adocao
END ONTOLOGY

ONTOLOGY adocao_de_ia
    descricao: Decisão de incorporar inteligência artificial aos processos da organização
    grupo: desfechos
END ONTOLOGY

1.5 Passo 5: Registrar as fontes

Substitua o conteúdo de references.bib por:

@misc{entrevista_joao2026,
  author = {Silva, João},
  title = {Entrevista sobre adoção de IA},
  year = {2026},
  note = {Gerente de TI, empresa de médio porte (dados fictícios)}
}

@misc{entrevista_maria2026,
  author = {Santos, Maria},
  title = {Entrevista sobre resistência tecnológica},
  year = {2026},
  note = {Analista de sistemas, startup (dados fictícios)}
}
Entrevistas reais

Não registre nomes de participantes. Use chaves neutras (ent01, ent02) e retire dados identificadores dos textos.

1.6 Passo 6: Criar as anotações

Agora vem a parte principal. Substitua o conteúdo de annotations.syn por:

SOURCE @entrevista_joao2026
END SOURCE

ITEM @entrevista_joao2026
    quote: "O custo inicial é proibitivo para nossa escala de operação"
    memo: O entrevistado apresenta uma barreira econômica à adoção de IA
    code: custo, adocao_de_ia
    chain: custo -> INIBE -> adocao_de_ia
END ITEM

ITEM @entrevista_joao2026
    quote: "Parece muito complexo, não temos gente que saiba fazer"
    memo: A falta de capacitação técnica aparece como obstáculo
    code: facilidade_de_uso
END ITEM

SOURCE @entrevista_maria2026
END SOURCE

ITEM @entrevista_maria2026
    quote: "Se fosse mais barato, a gente testaria. A tecnologia parece boa"
    memo: Reconhece a utilidade, mas o custo limita a decisão
    code: custo, utilidade_percebida
    chain: custo -> INIBE -> adocao_de_ia
    chain: utilidade_percebida -> FAVORECE -> adocao_de_ia
END ITEM
Observe o padrão

Cada ITEM liga:

  1. uma citação literal (quote)
  2. a sua interpretação (memo)
  3. conceitos (code)
  4. quando a fonte afirma, uma relação (chain)

Isso é rastreabilidade bidirecional: da evidência à interpretação e vice-versa.

1.7 Passo 7: Validar

Para conferir só a escrita de um arquivo:

synesis check annotations.syn

Para validar o projeto inteiro (template, bibliografia, anotações e ontologia):

synesis compile project.synp --stats

A saída termina assim:

Compilation Summary:
  Sources        2
  Items          3
  Model entries  4  (4 concepts)
  Active codes   4
  Chains         3
Checkpoint ✓

Nenhuma linha com [ERROR] ou [WARNING]: o projeto está consistente.

1.7.1 Veja o compilador trabalhar

Acrescente ao final de annotations.syn um item com um código que não existe e uma relação não declarada:

ITEM @entrevista_maria2026
    quote: "Precisaríamos de treinamento"
    memo: Aponta a necessidade de capacitação
    code: treinamento
    chain: treinamento -> EXIGE -> adocao_de_ia
END ITEM
synesis compile project.synp --check-codes

O compilador aponta o arquivo, a linha e o problema: a relação EXIGE é um erro, e o código treinamento, sem conceito na ontologia, um aviso. Remova o item antes de continuar.

1.8 Passo 8: Exportar

synesis compile project.synp --json saida/analise.json --csv saida/csv --xls saida/analise.xlsx

O que foi gerado:

saida/
├── analise.json        # estrutura completa do projeto
├── analise.xlsx        # planilha com várias abas
└── csv/
    ├── items.csv       # uma linha por unidade analítica
    ├── ontologies.csv  # conceitos
    └── chains.csv      # relações (origem, relação, destino)

Há sources.csv quando o template declara campos de SOURCE.

Explore os resultados

Abra analise.xlsx no Excel ou no LibreOffice: você já pode contar, filtrar e cruzar os seus dados qualitativos, e cada linha aponta o arquivo e a linha de origem.

1.8.1 Declare as exportações no projeto

Para não repetir as opções, declare os artefatos em project.synp:

PROJECT adocao_tecnologica
    TEMPLATE "template.synt"
    INCLUDE BIBLIOGRAPHY "references.bib"
    INCLUDE ANNOTATIONS "annotations.syn"
    INCLUDE ONTOLOGY "ontology.syno"

    QUESTIONS
        Q1: Que fatores os entrevistados apontam para adotar ou não IA?
    END QUESTIONS

    EXPORT JSON
        OUTPUT "saida/analise.json"
    END EXPORT

    EXPORT XLS
        OUTPUT "saida/analise.xlsx"
    END EXPORT
END PROJECT

E execute:

synesis export project.synp

1.9 Passo 9 (opcional): VS Code

Com a extensão Synesis instalada, abra a pasta do projeto:

code .

Você terá realce de sintaxe, validação em tempo real, autocompletar de códigos e relações e as visões de referências, códigos, relações e ontologia. Veja o Tutorial Synesis Explorer.

1.12 Troubleshooting

1.12.1 command not found: synesis (ou “não é reconhecido como um comando”)

A pasta de scripts do Python não está no PATH.

python -m pip install --user synesis

Abra um terminal novo depois da instalação. Como alternativa, instale com uv tool install synesis.

1.12.2 Template 'template.synt' not found

Ou o caminho está errado (rode os comandos na pasta do projeto), ou o template tem um erro de sintaxe: nos dois casos a mensagem pode ser essa. Confira com:

synesis validate-template template.synt

As causas mais comuns são version: em linha própria, um índice de ORDERED sem colchetes e um END faltando.

1.12.3 Code 'XYZ' is not defined in the organizing model

Você usou um código que não tem bloco em ontology.syno. Acrescente o ONTOLOGY correspondente ou corrija a grafia.

1.12.4 Reference '@abc' not found in the .bib

A chave não existe em references.bib, ou está escrita de outra forma.

1.12.5 Quero entender um erro

Todos estão no Guia de Erros. No terminal: pip install synesis-help e synesis-help lookup E010.

Ficou com dúvidas? Abra uma discussão no GitHub Discussions ou consulte a documentação.
